**Yapılacaklar:**
1. `executeStockCommand({ principal, slug|tenantId, commandType, clientKey, input, permission, plan(tx, input), apply(tx, locked, ctx) })`: `withMembership(permission)` → **hemen** `set_config('lock_timeout'|'statement_timeout', …, true)` (A-75; ADR-018 §2/§5, MINOR-2) → `assertWarehouseInScope` → idempotency (ADR-018 §2) → `acquireStockLocks(plan)` → `apply` → `appendAudit` → numara (gerekiyorsa, **en son** — ADR-018 §7) → idempotency `COMPLETED` + beyaz listeli sonuç; hepsi tek transaction.
2. `idempotency.ts`: kanonik JSON (anahtar sıralı, sunucu alanları hariç) + SHA-256; `IDEMPOTENCY_KEY_REQUIRED`; mevcut kayıtta `actor_user_id ≠ çağıran` veya `request_hash` farklı → `IDEMPOTENCY_MISMATCH` (saklı sonuç dönmez; MINOR-3); `COMPLETED` → saklı sonuç; `REJECTED` → saklı hata kodu; `IN_PROGRESS` → "işleniyor" (T-222). **Ret (M-1, ADR-018 §3):** iş kuralı reddinde ana transaction geri alınır, ardından ayrı kısa transaction'da (`withMembership` + zaman aşımları) `REJECTED` + `error_code` kaydı `ON CONFLICT DO NOTHING` ile yazılır; geçici hatalar (`VERSION_CONFLICT` tükenmesi, bağlantı, `FORBIDDEN`, `UNAUTHENTICATED`) ve `IDEMPOTENCY_MISMATCH` kaydedilmez. Ret kaydı yazılamazsa asıl ret döner + hata logu. `result` yazımı beyaz listeden (ADR-017 §10) — liste dışı alan kod tarafında da reddedilir.
3. `retry.ts`: `40P01`/`40001`/`55P03` → en çok 3 deneme, jitter (A-75); iş kuralı `AppError` denenmez; tükenince `VERSION_CONFLICT` + `retryable`. Deneme sayısı ve toplam bekleme yapılandırılmış log alanı (değer, kişisel veri yok).
4. `documents.ts`: `createStockDocument` (`document.create`; `DRAFT`; satır sayısı > 2.000 → `DOCUMENT_TOO_LARGE`, A-07), `updateDraft` (sürüm denetimi), `approveDocument` (`document.approve`), `cancelDocument` (`DRAFT`/`APPROVED` → `CANCELLED`; `POSTED` → `DOCUMENT_STATE`); her geçiş `document_status_history` + audit. Görev ayrımı yok (A-03 kapalı). **İşleme kilidi (M-6, ADR-018 §6):** belge satırı `FOR UPDATE` okunur; `posting_job_id IS NOT NULL` iken `updateDraft`, `approveDocument`, `cancelDocument` → `DOCUMENT_STATE` (ortak `assertNotProcessing` yardımcısı; T-217/T-221 de kullanır).
5. `numbering.ts`: `number_sequences` satır kilidiyle atomik (`INSERT … ON CONFLICT DO UPDATE … RETURNING`); dönem ve biçim A-70; boşluk kabul (A-05).
6. Belge türü sürümü (I-11): belge oluşturulurken `document_type_versions` sistem v1 kimliği yazılır (A-79).
7. `index.ts` + `package.json` `exports["./stock"]`.
