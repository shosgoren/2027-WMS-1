2. `idempotency.ts`: kanonik JSON (anahtar sıralı, sunucu alanları hariç) + SHA-256; `IDEMPOTENCY_KEY_REQUIRED`, `IDEMPOTENCY_MISMATCH`, `COMPLETED` → saklanan sonuç; `IN_PROGRESS` → "işleniyor" sonucu (eşik üstü belge, T-222). Reddedilen istekte satır geri alınır (ADR-018 §3).
3. `retry.ts`: `40P01`/`40001`/`55P03` → en çok 3 deneme, jitter (A-75); iş kuralı `AppError` denenmez; tükenince `VERSION_CONFLICT` + `retryable`. Deneme sayısı ve toplam bekleme yapılandırılmış log alanı (değer, kişisel veri yok).
