# T-218: Bağımsız doğrulama — AC-22 (çift teslim) ve AC-23 (iki işleyici örneği), AC-02 worker olayı kolu
**Faz:** 2 · **Ajan:** qa-verifier · **Bağımlılık:** T-211, T-214 (aynı int dalında) · **Dal:** `feat/T-218-qa-queue` → `int/faz2-kuyruk`
**Amaç (tek cümle):** Postgres kuyruğunda (ADR-005, ADR-019) aynı işin iki kez teslim edilmesinin tek etki ürettiğini, iki işleyici örneğinin aynı işi birlikte yürütmediğini ve haricî çağrıya aynı idempotency anahtarının gittiğini uygulayıcıdan bağımsız kanıtlamak.
**Okuma listesi (≤5):** `docs/ACCEPTANCE.md AC-02, AC-22, AC-23`, `docs/adr/ADR-019.md`, `packages/queue-adapter/src/consume.ts` (T-214), `tests/integration/queue/enqueue.int.test.ts` (pg-boss test kurulumu deseni; ilk 50 satır), `apps/worker/src/jobs/send-email.ts`
**Dokunulacak dosyalar (≤10):** `tests/integration/ac/ac-22-duplicate-delivery.int.test.ts`, `tests/integration/ac/ac-23-concurrent-consumers.int.test.ts`, `tests/integration/ac/ac-02-worker-event.int.test.ts`, `tests/.ac-baseline.json`

**Yapılacaklar:**
1. AC-22: test tüketicisi (yalnızca test dosyasında kayıtlı, `consumeOnce` kullanan) yan etkiyi yazar ve onaydan önce süreç düzeyinde çöker (iş `fail`/zaman aşımı ile yeniden teslime zorlanır) → ikinci teslim `processed_events` çakışmasıyla sessizce onaylanır; yan etki tablosunda tek satır. Haricî kol: `send-email` işi sahte sağlayıcı sunucusuna (yerel HTTP) iki kez teslim → her çağrıda aynı `Idempotency-Key`; ilk çağrı başarılıysa ikinci çağrı yapılmaz.
2. AC-23: iki ayrı `createJobQueue` örneği (ayrı havuzlar) aynı kuyruktan 500 işi eşzamanlı tüketir → her iş kimliği için yürütme sayacı = 1; toplam işlenen = 500; `processed_events` satır sayısı = 500.
3. AC-02 (worker olayı kolu): aynı olay kimliğiyle ikinci `consumeOnce` → önceki sonuç (etki yok); farklı tenant bağlamında aynı olay kimliği → tenant A'nın satırı B'den görünmez.
4. Başlıklar `@AC-22`, `@AC-23`, `@AC-02`; dosya başı katman notu. `pnpm check:ac-ratchet --update`.

**Kabul ölçütü:** `pnpm test:ac -- AC-22 AC-23` PASS; `pnpm test:ac -- AC-02` yeni testi sayar (stok kolu T-220); `pnpm test:int` tam koşu PASS; `pnpm verify` OK; `pnpm check:all` OK.
**Kapsam dışı:** AC-16 (stok komutları sürerken worker durması — T-228), AC-32/33 (koşul yok: `adr005_separate_broker=false`).
