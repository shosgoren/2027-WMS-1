# T-113: Kimlik domain'i — rol × izin matrisi, `requireTenantAccess`, hata kodları (`packages/domain`, `packages/shared`)
**Faz:** 1 · **Ajan:** backend-dev · **Bağımlılık:** T-103, T-112, T-112b · **Dal:** `feat/T-113-tenant-access` → `int/faz1-auth`
**Amaç (tek cümle):** Oturumdan gelen kimliği, slug ile seçilen tenant'ta `withMembership` üzerinden güncel üyelik + rol iznine bağlayan tek giriş yolunu (`requireTenantAccess` / `runTenantCommand`) ve A-45 izin matrisini yazmak; web, worker ve sonraki import aynı yolu kullanır.
**Okuma listesi (≤5):** `docs/adr/ADR-016.md §4–6`, `docs/OPEN_QUESTIONS.md A-03, A-38, A-45, A-46, A-51`, `docs/spec/15-engineering.md §Kod, §API sözleşmesi`, `packages/db/src/with-membership.ts`, `packages/auth/src/index.ts` (`getPrincipal`)
**Dokunulacak dosyalar (≤10):** `packages/shared/package.json`, `packages/shared/tsconfig.json`, `packages/shared/src/errors.ts`, `packages/domain/package.json`, `packages/domain/tsconfig.json`, `packages/domain/src/identity/permissions.ts`, `packages/domain/src/identity/access.ts`, `tests/integration/identity/tenant-access.int.test.ts`, `docs/MAP.md`, `pnpm-lock.yaml`

**Yapılacaklar:**
1. `errors.ts`: `AppError` + 15 §API sözleşmesindeki kodların Faz 1'de kullanılanları (`VALIDATION_FAILED`, `UNAUTHENTICATED`, `FORBIDDEN`, `TENANT_SUSPENDED`, `TENANT_CLOSING`, `NOT_FOUND`, `RATE_LIMITED`) + ayrıntı alanı (`MFA_REQUIRED`, `RECENT_AUTH_REQUIRED`); HTTP eşlemesi; kullanıcıya dönen mesaj anahtarı (i18n) — iç ayrıntı/SQL sızmaz.
2. `permissions.ts`: `ROLE_KEYS`, `PERMISSIONS` (ADR-016 §4), `ROLE_PERMISSIONS` = **A-45** birebir (tek kaynak; değişiklik A-45/Q-22 güncellemesi ister), `hasPermission(roles, perm)`. Görev ayrımı (A-03) bu kartta yok.
3. `access.ts`: `runTenantCommand({ db, principal, tenantSlug, permission, recentAuth? }, fn)` → principal yoksa `UNAUTHENTICATED`; slug → tenant kimliği `withUser` ile **yalnızca üye olunan** tenant'lar arasında çözülür (üye değilse `NOT_FOUND` — varlık sızdırılmaz); sonra `withMembership(... permission)`; `TENANT_ADMIN` + A-38 MFA zorunlu + `principal.mfaVerified=false` (demo tenant hariç) → `FORBIDDEN`/`MFA_REQUIRED`; `fn(tx, membership)`. Okuma için `runTenantQuery` aynı yoldan. Domain kodu Next/Better Auth import etmez (principal düz veri).
4. `MAP.md`: `packages/domain/`, `packages/shared/` satırları `var`; `packages/auth/` satırı eklenir (check-docs).
5. `tenant-access.int.test.ts`: her rol için izinli/izinsiz bir eylem; başka tenant'ın slug'ı → `NOT_FOUND`; REMOVED üyelik → `FORBIDDEN`; SUSPENDED → `TENANT_SUSPENDED`; MFA'sız TENANT_ADMIN → `MFA_REQUIRED`; demo tenant'ta MFA muafiyeti.
