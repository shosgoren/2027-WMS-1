# T-120: Bağımsız doğrulama — AC-18 (çıkarılan kullanıcının eski oturumuyla yazma) uçtan uca sunucu yolu
**Faz:** 1 · **Ajan:** qa-verifier · **Bağımlılık:** T-117, T-117b (aynı int dalında; UI gerekmez) · **Dal:** `feat/T-120-qa-ac18` → `int/faz1-uyelik`
**Amaç (tek cümle):** Gerçek oturum çerezi ve gerçek Server Action/komut yolu üzerinden, tenant yöneticisi tarafından çıkarılan kullanıcının (ve askıya alınan tenant'taki kullanıcının) çıkarılmadan önce aldığı oturumla yaptığı yazmanın reddedildiğini `@AC-18` testleriyle kanıtlamak.
**Okuma listesi (≤5):** `docs/ACCEPTANCE.md AC-18`, `docs/spec/02-tenancy-auth.md §Oturum`, `docs/adr/ADR-014.md §3`, `packages/domain/src/identity/memberships.ts`, `tests/integration/ac/ac-18-membership-db.int.test.ts` (T-104)
**Dokunulacak dosyalar (≤10):** `tests/integration/ac/ac-18-revoked-session.int.test.ts`, `tests/integration/fixtures/principals.ts`, `tests/integration/security/password-reset-scope.int.test.ts`, `tests/integration/security/token-scan-queue.int.test.ts`, `tests/unit/web/safe-next.test.ts`, `tests/.ac-baseline.json`

**Yapılacaklar:**
1. Senaryo 1: U, tenant A'da sahip olmayan `TENANT_ADMIN` (Faz 1'de yazma komutları `users.manage`/`settings.manage` gerektirir); MFA fikstürle doğrulanmış oturum açar (Better Auth gerçek akışı, çerez alınır). Sahip `removeMember(U)` komutunu çalıştırır. U'nun **aynı çereziyle** A'da `inviteMember` → `FORBIDDEN`; davet satırı yok; audit'te U adına yeni satır yok.
2. Senaryo 2: U'nun tenant B üyeliği sürer → aynı çerezle B'ye yazma **başarılı** (oturum iptal edilmedi, yalnızca A üyeliği; ADR-014 §3).
3. Senaryo 3: tenant A `SUSPENDED` (A-49: migration rolüyle fikstür) → A'daki her üyenin eski oturumuyla yazma `TENANT_SUSPENDED`.
4. Senaryo 4 (yarış): U'nun yazma transaction'ı `withMembership` içinde beklerken çıkarma komutu gelir → çıkarma, yazma bitene kadar bekler (FOR SHARE); sıra tersse yazma reddedilir; ara durumda "çıkarılmış ama yazmış" yok.
5. Senaryo 5: rolü `TENANT_ADMIN`'den `READ_ONLY`'ye düşürülen kullanıcının eski oturumuyla `inviteMember` → `FORBIDDEN` (güncel yetki).
6. Başlıklar `@AC-18`; `pnpm check:ac-ratchet --update`.
