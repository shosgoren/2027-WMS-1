**Amaç (tek cümle):** ADR-006 `ObjectStorage` arayüzünü, anahtarı doğrulanmış tenant bağlamından türeten ve başka tenant önekli anahtarı ağ çağrısı yapmadan reddeden bir S3 bağdaştırıcısıyla kurmak; tüm önbellek kullanımını tenant kimliğini içeren tek bir anahtar yardımcısına bağlamak (AC-04 dosya ve cache katmanlarının üretim tarafı).
**Okuma listesi (≤5):** `docs/adr/ADR-006.md`, `docs/spec/02-tenancy-auth.md §Tenant bağlamı (cache/dosya/job satırı)`, `docs/OPEN_QUESTIONS.md A-52`, `docker-compose.yml` (`minio` servisi) + `tests/integration/harness/global-setup.ts`, S3 istemci kütüphanesi belgesi (seçilen paket; Context7, G-04)
**Dokunulacak dosyalar (≤10):** `packages/shared/src/storage.ts`, `packages/shared/src/cache-key.ts`, `packages/storage/package.json`, `packages/storage/tsconfig.json`, `packages/storage/src/index.ts`, `packages/storage/src/storage.test.ts`, `tests/integration/storage/object-storage.int.test.ts`, `tests/integration/harness/global-setup.ts`, `docs/STACK.md`, `pnpm-lock.yaml` · Supervisor eki (inceleme @7e66131 MAJOR): `packages/storage/src/context.ts` (export edilmeyen bağlam üreticisi + marka WeakSet)

**Yapılacaklar:**
1. `storage.ts` arayüzü: `put(ctx, relativeKey, body, meta)`, `get(ctx, key)`, `delete(ctx, key)`, `signedGetUrl(ctx, key, ttlSec)`; `ctx` = `withMembership`'ten gelen doğrulanmış tenant kimliği (düz `tenantId` dizgisi kabul edilmez — marka tipi). Anahtar = `tenants/<tenantId>/<relativeKey>`; `relativeKey` normalize edilir (`..`, `/` başı, `\`, boş bölüm → `VALIDATION_FAILED`). `get/delete/signedGetUrl` öneki `ctx` tenant'ı değilse ağ çağrısı yapmadan `FORBIDDEN`.
2. S3 istemcisi: seçenekleri karşılaştır (ör. `@aws-sdk/client-s3` Apache-2.0 / `aws4fetch` MIT) — boyut, bakım, imzalı URL desteği; seçimi tam sürümle `STACK.md`'ye yaz. Kimlik bilgileri ortamdan; bucket özel (ADR-006); root olmayan erişim anahtarı (T-003 takibi) yerelde de.
3. `cache-key.ts`: `tenantCacheKey(ctx, namespace, ...parts)` → `t:<tenantId>:<namespace>:…`; Faz 1'de uygulama önbelleği yoksa yalnızca yardımcı + sözleşme (her gelecek önbellek bunu kullanır) — kullanan ilk kart AC-04 cache testini genişletir. Next `"use cache"`/`unstable_cache` kullanımı bu kartta yok.
4. Bayrak: `STORAGE_ENABLED` staging'de kapalı (A-52, Tigris yok); kapalıyken bağdaştırıcı oluşturulmaz, çağrı açık hata.
5. `global-setup.ts`: compose hedefinde `minio` servisi de kaldırılır (bucket + root olmayan anahtar test başında oluşturulur); neon hedefinde MinIO yoksa depolama testleri **atlanmaz**, açık hatayla düşer veya hedefin MinIO URL'si zorunlu — seçimi rapora (G-11: koşullu atlama yasak).
6. Testler: unit — anahtar normalizasyonu, önek reddi (ağsız). int (MinIO) — A `put/get` çalışır; A bağlamıyla B önekli anahtar → `FORBIDDEN`, MinIO'ya istek gitmez (istek sayacı); imzalı URL süresi.
