# T-116: İşlemsel e-posta — `Mailer` (Resend / Mailpit / devre dışı), TR/EN şablonlar, `email.send` işi
**Faz:** 1 · **Ajan:** backend-dev · **Bağımlılık:** T-115 · **Dal:** `feat/T-116-mailer` → `int/faz1-kuyruk-eposta`
**Amaç (tek cümle):** Davet ve parola sıfırlama e-postalarını kuyruk üzerinden, ADR-013'teki Resend kısıtına (doğrulanmış alan adı yokken yalnızca izinli alıcı) uyarak gönderen ve teslim edilemeyecek gönderimi **önceden** bildiren (`canDeliver`) `Mailer` katmanını kurmak.
**Okuma listesi (≤5):** `docs/adr/ADR-013.md`, `docs/OPEN_QUESTIONS.md A-42, A-50, A-53`, `docs/spec/13-reporting-notify-print.md §Bildirim`, `packages/shared/src/queue.ts` (T-115), Resend REST API (e-posta gönderme, idempotency başlığı) ve Mailpit HTTP gönderme API'si belgesi (Context7/resmî; uç nokta ve alan adları doğrulanır, G-04)
**Dokunulacak dosyalar (≤10):** `packages/shared/src/mailer.ts`, `packages/shared/src/seal.ts`, `apps/worker/src/mail/resend.ts`, `apps/worker/src/mail/mailpit.ts`, `apps/worker/src/mail/templates.ts`, `apps/worker/src/mail/mail.test.ts`, `apps/worker/src/jobs/send-email.ts`, `apps/worker/src/main.ts`, `.env.example`, `fly.staging.toml`

**Yapılacaklar:**
1. `mailer.ts`: `MailMode = "resend" | "mailpit" | "disabled"` (`MAIL_MODE`), `canDeliver(recipient)`: `disabled` → false; `resend` + `MAIL_VERIFIED_DOMAIN` yok → yalnızca `MAIL_RESTRICTED_RECIPIENTS` (virgüllü; sır olarak tutulur, repoya girmez) içindekiler; `mailpit` → true. Komutlar (T-117) gönderimi kuyruğa yazmadan önce bunu çağırır; false ise kendi geri dönüş yolunu kullanır (A-42).
2. Gönderim yeni bağımlılık olmadan `fetch` ile (Resend REST; Mailpit HTTP gönderme uç noktası — Mailpit sürümünde yoksa SMTP için tek bağımlılık gerekçesiyle rapora ve dur). Resend çağrısında idempotency anahtarı = iş kimliği (A-53).
3. Şablonlar (`templates.ts`): `invitation`, `password_reset` — TR varsayılan, EN; düz metin + basit HTML; bağlantı dışında kişisel veri yok; ürün adı "Etkin WMS". Metinler `apps/web/messages` ile aynı anahtar düzeninde ama worker'a ait dosyada (tek kaynak ihlali → bulgu olarak raporla, Faz 1'de kabul).
4. `send-email.ts`: `email.send` işi `withSystemTenant` ile tenant'ın ACTIVE olduğunu doğrular; alıcı adresi ve bağlantı **loglanmaz** (maskeli alıcı: `a***@d***`); hata yeniden denemeye bırakılır (pg-boss retry), sessiz yutma yok.
5. Ortam: `.env.example`'a `MAIL_MODE=mailpit`, Mailpit adresi (yer tutucu); `fly.staging.toml` `[env]`: `MAIL_MODE = "resend"` (sırsız). `MAIL_RESTRICTED_RECIPIENTS` ve `RESEND_API_KEY` Fly sırrı (T-105 iş akışı adları; değer kullanıcı hesabından — yoksa staging fiilen "ekranda bağlantı" yolunda kalır).
6. `mail.test.ts`: `canDeliver` tablosu; şablonlar TR/EN üretir ve bağlantıyı içerir; log çıktısında tam adres/bağlantı yok; Resend isteği doğru başlıkları taşır (sahte `fetch`).
