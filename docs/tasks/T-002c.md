# T-002c: `apps/worker` — kalıcı worker süreci iskeleti + zarif kapanış
**Faz:** 0 · **Ajan:** devops · **Bağımlılık:** T-002a, T-002b (ikisi de `pnpm-lock.yaml`'a dokunur → seri) · **Dal:** `feat/T-002c-worker-skeleton` → `int/faz0-iskelet`
**Amaç (tek cümle):** `apps/worker`'ı web'den bağımsız başlayan, SIGTERM/SIGINT'te zarif kapanan, henüz iş tüketmeyen uzun ömürlü Node.js süreci olarak kurmak.
**Okuma listesi (≤5):** `docs/adr/ADR-001.md §Karar, §Sonuçlar`, `docs/adr/ADR-005.md §Karar`, `docs/STACK.md §ADR-005`, `docs/spec/14-reliability-ops.md` (Deploy maddesi), `docs/tasks/T-002a.md`
**Dokunulacak dosyalar (≤10):** `apps/worker/package.json`, `apps/worker/tsconfig.json`, `apps/worker/src/main.ts`, `apps/worker/src/lifecycle.ts`, `apps/worker/src/lifecycle.test.ts`, `pnpm-lock.yaml`, `.gitignore` (yalnızca `apps/web/next-env.d.ts` satırı — T-002b bulgusu)

**Yapılacaklar:**
1. Çalıştırma: `tsc` ile `dist/`'e derle, `node dist/main.js`; ek çalışma zamanı bağımlılığı (tsx vb.) eklenmez. `typecheck` ve `build` betikleri; `tsconfig` kök tabanı `extends` eder.
2. `lifecycle.ts`: `start()` / `stop(reason)`; SIGTERM ve SIGINT tek kez işlenir (ikinci sinyal = zorla çıkış, kod ≠ 0); kapanış zaman aşımı `WORKER_SHUTDOWN_TIMEOUT_MS` ortam değişkeninden, varsayılanı kodda sabit ve rapora yazılır. Kayıtlı kapanış kancaları (ileride kuyruk/DB havuzu) sırayla çağrılır.
3. Yakalanmamış hata / reddedilmiş promise → yapılandırılmış log (JSON satır: `level`, `msg`, `ts`) + çıkış ≠ 0; hata yutulmaz (G-07).
4. Kuyruk tüketimi **yok**: worker yalnızca "started" log'u basar ve bekler. Kuyruk kütüphanesi kurulmaz.
5. ADR-005 girdisi (araştırma, kod değil): pg-boss ve graphile-worker için lisans, son yayın tarihi, desteklenen PostgreSQL/Node sürümleri, transaction-mode pooler arkasında çalışma notu (LISTEN/NOTIFY vb. session özelliği kullanıyor mu) — paket belgelerinden/Context7'den, kaynak bağlantısıyla **rapordaki Bulgular** bölümüne. Seçim yapılmaz; ADR-005 eki architect kartıdır.

**Kabul ölçütü:**
- `pnpm verify` → üç adım OK; `lifecycle.test.ts`: (a) kancalar kayıt sırasıyla bir kez çağrılır, (b) ikinci `stop` çağrısı kancaları tekrar çağırmaz, (c) zaman aşımını aşan kanca → çıkış kodu ≠ 0 sonucu.
- `pnpm --filter @wms/worker build && node apps/worker/dist/main.js` başlar, web çalışmıyorken de "started" log'u; `kill -TERM <pid>` → "shutdown complete" log'u, çıkış kodu 0 (komutlar ve çıktı özeti rapora).
**Kapsam dışı:** `JobQueue` arayüzü, `packages/queue-adapter`, kuyruk kütüphanesi kurulumu, DB bağlantısı, OpenTelemetry, Dockerfile/deploy.
**Gerekli inceleme:** Risk matrisi "Diğer" (kuyruk tüketicisi henüz yok) → security-reviewer gerekmez. `int/faz0-iskelet` paketiyle Supervisor incelemesi.
