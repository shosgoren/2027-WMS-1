**Yapılacaklar:**
1. Saha sevk: sevke hazır siparişler (SEVK'te rezerve miktarı olan) → sipariş seç → satırlar ürün okutarak doğrulanır → satır başına sevk miktarı (varsayılan = SEVK'teki rezerve) → onay; kısmi sevkte "kalan X adet SEVK'te bekliyor" bilgisi.
2. Çift gönderim: "Sevk et" düğmesi gönderimde kilitlenir; aynı anahtar yeniden gönderilir; ikinci farklı anahtarlı deneme sunucu reddini "Bu sipariş için sevk edilecek toplanmış miktar yok" olarak gösterir (AC-10 UI kolu).
3. İade: sipariş ayrıntısından iletişim kutusu (masaüstü) ve saha iade akışı — sipariş/sevk satırı seç → ürün okut → miktar → hedef kabul lokasyonu → neden (kişisel veri uyarısı) → onay; "iade karantinaya alındı, kalite onayı bekliyor" sonucu.
4. `shipping-actions.test.ts`: anahtar yaşam döngüsü, düğme kilidi, hata eşlemesi (`INSUFFICIENT_STOCK`, `RETURN_EXCEEDS_SHIPPED`, `LOCATION_LOCKED`).
