**Yapılacaklar:**
1. `processed_events (tenant_id NULL, consumer, event_id, processed_at)` `UNIQUE NULLS NOT DISTINCT (tenant_id, consumer, event_id)` (MINOR-4). RLS (`wms_app`): tenant satırı `tenant_id = current`; `tenant_id IS NULL` satırı yalnızca tenant bağlamı boşken. `SELECT, INSERT`; UPDATE/DELETE yok.
2. `stock_consistency_runs (tenant_id, id, started_at, finished_at, status RUNNING|OK|MISMATCH|FAILED, checked_dimensions, mismatch_count, findings jsonb, created_xid)`: `created_xid` `BEFORE INSERT` ile zorlanır (MINOR-1); `wms_app` `SELECT`, `INSERT`, `UPDATE (finished_at, status, checked_dimensions, mismatch_count, findings)`; yazma politikası `WITH CHECK (tenant_id = current AND current_setting('app.system_reason', true) = 'queue.stock.consistency.check')`.
3. `stock_consistency_signals (id, occurred_at, status OK|MISMATCH|FAILED, mismatch_count, created_xid)` — **tenant kimliği yok** (M-7); append-only (UPDATE/DELETE/TRUNCATE tetikleyiciyle ret); `wms_app` yalnızca `INSERT` (politika: aynı `app.system_reason` koşulu), `SELECT` yok; `wms_ops` `SELECT`. `/api/health` bu tabloyu okumaz.
4. `wms_probe.active_tenant_ids(after uuid, lim int) RETURNS SETOF uuid`: `SECURITY DEFINER`, sahibi `wms_identity_probe` (ADR-015 SET ROLE kalıbı; `CREATE` geçici verilip geri alınır; son ifade `current_user = session_user` denetimi), `SET search_path = pg_catalog, pg_temp`, gövde şema nitelikli, yalnızca `status = 'ACTIVE'`, `id > after ORDER BY id LIMIT least(lim, 500)`; `REVOKE EXECUTE … FROM PUBLIC`; `GRANT EXECUTE` + `GRANT USAGE ON SCHEMA wms_probe` yalnızca `wms_worker`. `wms_app`/`wms_auth` EXECUTE yok.
5. RLS/FORCE (tenant tabloları); down ters sıra (işlev SET ROLE ile düşürülür). Drizzle şeması + sapma (`packages/db/src/index.ts`'e dokunulmaz — T-210 ile çakışma önlenir).
6. `seedWorld`: A ve B için `processed_events` ve `stock_consistency_runs` satırı (AC-04 DB dinamik testi).
7. `reliability-schema.int.test.ts`: aynı (tenant, consumer, event_id) ikinci INSERT → 23505, farklı tenant aynı (consumer, event_id) → iki satır; A bağlamında B satırı görünmez; tenant bağlamındayken platform satırı görünmez; `app.system_reason` olmadan `stock_consistency_runs`/`signals` INSERT → RLS reddi; `wms_app` `signals` SELECT → 42501; `wms_worker` `active_tenant_ids` → yalnızca ACTIVE tenant'lar (SUSPENDED hariç), sayısı migration rolüyle sayılanla eşit; `wms_app` ile çağrı → 42501; katalog: işlevin `prosecdef`, `proowner = wms_identity_probe`, `proconfig` search_path.
