# T-008b: `check:tests` — devre dışı test yakalayıcı
**Faz:** 0 · **Ajan:** devops · **Bağımlılık:** T-008a (T-008c ile paralel) · **Dal:** `feat/T-008b-check-tests` → `int/faz0-bekciler-1`
**protected: true** (beyan; onay değildir) — bekçi betiği.
**Amaç (tek cümle):** Test dosyalarında `skip`/`only`/`todo`/`xit`/`xdescribe`/koşullu atlamayı statik olarak yakalayan, lint yapılandırmasına dokunmayan `pnpm check:tests`'i yazmak.
**Okuma listesi (≤5):** `docs/agents/PROTOCOL.md §3b` (`check:tests` satırı) ve `§Karantina kuralı`, `scripts/guards/lib/output.mjs`, `scripts/guards/lib/testkit.mjs`, kurulu `typescript` paketinin AST API tip tanımı (G-04)
**Dokunulacak dosyalar (≤10):** `scripts/guards/tests.mjs`, `scripts/guards/tests.test.mjs` (fixture'lar `lib/testkit.mjs` ile test içinde)

**Yapılacaklar:**
1. Kapsam: depo içindeki tüm test dosyaları (`*.test.{ts,tsx,mjs}`, `*.spec.{ts,tsx,mjs}`, `tests/**`), yalnızca değişenler değil — eski bir `skip` de yakalanır. Yalnızca `node_modules`, `.artifacts`, `.next`, `dist` hariç (başka muafiyet yok; bekçi testlerindeki örnek kod dize olarak tutulur, AST'de çağrı değildir).
2. TypeScript AST ile (regex değil; yorum ve dizedeki "skip" yanlış alarm vermez): `it|test|describe|suite` üzerinde `.skip/.only/.todo/.skipIf/.runIf/.fails` ve `concurrent.skip` vb. zincirler, `xit/xtest/xdescribe/fit/fdescribe`, Playwright `test.skip()/test.fixme()/test.fail()/test.slow` gövde içi çağrıları, `ctx.skip()`.
3. Koşullu atlama: test/describe gövdesinin ilk deyimi `if (<herhangi>) return` ise ve koşul `process.env`, `CI` veya platform okuyorsa → `CONDITIONAL_SKIP`.
4. Neden kodları: `SKIP`, `ONLY`, `TODO`, `CONDITIONAL_SKIP`; her bulguda dosya:satır.
5. Atlama istisnası **yok**, `@quarantine` etiketli atlama dahil (`QUARANTINE_NOT_SUPPORTED`). Gerekçe: §Karantina "testler her CI çalıştırmasında yine koşturulur" der; bu yüzden karantina `skip` ile değil, T-008e'de "koşar, başarısızlığı kapıyı kırmaz" olarak uygulanır. PROTOCOL §3b'deki "tek istisna" ifadesi bu daha katı biçimle karşılanır.
6. Yalnızca T-002a'nın kurduğu `typescript` paketi (`.mjs`'ten import; derleyici API'si); yeni bağımlılık yok.

**Kabul ölçütü:** `pnpm vitest run scripts/guards/tests.test.mjs` yeşil; fixture'lar: her yasak biçim için ayrı FAIL + doğru neden kodu ve satır · yorumdaki `it.skip` ve dizedeki `"only"` → OK · temiz dosya → OK · `@quarantine` etiketli `it.skip` → FAIL `QUARANTINE_NOT_SUPPORTED`. Kendi dalında `pnpm check:tests` → OK. `pnpm verify` özeti raporda.
