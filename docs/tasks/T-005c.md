# T-005c: Bağımsız AC-05 ve AC-28 testleri (pooler arkasında, hedeften bağımsız)
**Faz:** 0 · **Ajan:** qa-verifier · **Bağımlılık:** T-005b · **Dal:** `feat/T-005c-ac05-ac28` → `int/faz0-pooler`
**Amaç (tek cümle):** AC-05 ve AC-28'i, uygulayıcıdan bağımsız olarak, hem docker PgBouncer'da hem Neon pooler'ında değişmeden koşan `@AC` etiketli testlerle kanıtlamak.
**Okuma listesi (≤5):** `docs/ACCEPTANCE.md AC-05, AC-28`, `docs/INVARIANTS.md I-01…I-03`, `docs/spec/02-tenancy-auth.md §Pooler uyumluluğu`, `docs/tasks/T-005b.md` (yalnızca dışa açık API ve fikstür), `.claude/agents/qa-verifier.md`
**Dokunulacak dosyalar (≤10):** `tests/integration/ac/ac-05-pooler-isolation.int.test.ts`, `tests/integration/ac/ac-28-runtime.int.test.ts`, `tests/unit/ac/ac-28-lint.test.ts`

**Yapılacaklar:**
1. Etiket: test adları `@AC-05` / `@AC-28` içerir (T-007 `test:ac` bunları toplar). Uygulama koduna dokunulmaz; hata bulunursa rapora yazılır, test gevşetilmez (G-11).
2. **AC-05** — havuz boyutu 1 ve 2 için ayrı koşu (istemci `poolMax`; compose'da PgBouncer pool boyutu `INT_PGBOUNCER_POOL_SIZE` ile eşleştirilir). `prepare` değeri harness'ten (`INT_DB_PREPARE` varsa o, yoksa `DB_CLIENT_SETTINGS`); kullanılan değer test çıktısına yazılır. "İstek" = bir `withTenant` çağrısı (Faz 0'da HTTP katmanı yok; yorum rapora **A-öneri** olarak). 2 tenant × 50 çağrı `Promise.all` ile eşzamanlı, tenant sırası karışık; her çağrı aynı parametreli sorguyu ≥2 kez çalıştırır (prepared statement yolunu tetikler).
3. AC-05 beklenenleri: her sonuçta yabancı tenant satırı **0**; her çağrı kendi tohum sayısını tam döndürür; prepared statement kaynaklı hata **0** (hata mesajı/SQLSTATE sayılır, tümü rapora); koşu sonrası ham istemciyle transaction dışı `SELECT` **0** satır (bağlam sızmadı). Ek: yarıda hata atıp geri alınan `withTenant` sonrası aynı havuzda bağlamsız sorgu 0 satır.
4. **AC-28 çalışma anı:** ham istemci (`@wms/db/internal`, `wms_app`, pooler) ile `withTenant` dışında: `SELECT` 0 satır; `INSERT` RLS ihlaliyle reddedilir (SQLSTATE assert edilir, mesaj metni değil); `UPDATE`/`DELETE` 0 satır etkiler.
5. **AC-28 lint:** ESLint Node API'si ile `lintText`, `filePath: packages/domain/src/__ac28_probe__.ts` (diske yazılmaz), içerik ham istemci import'u → T-005b'nin kural kimliğiyle **error**; aynı içerik `packages/db/src/` yolunda → hata yok (kuralın kapsamı doğru). Bu test `pnpm verify` unit adımında koşar.
6. Testler hedefe göre dallanmaz: aynı dosya `pnpm test:int` (compose) ve `pnpm test:int:neon`'da değişmeden koşar. Tohum veri sentetik UUID/metin (G-09).
