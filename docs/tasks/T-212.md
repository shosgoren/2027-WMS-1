# T-212: Lot, seri ve taşıma birimi kart komutları (model Faz 2, saha akışı 3A/3B)
**Faz:** 2 · **Ajan:** backend-dev · **Bağımlılık:** T-208 (`catalog/index.ts`), T-204 · **Dal:** `feat/T-212-traceability-domain` → `int/faz2-katalog`
**Amaç (tek cümle):** Lot (SKT tarih-only), seri (ürün içi tekil, A-72) ve iç içe taşıma birimi (döngüsüz, ADR-011) kartlarını oluşturan/sorgulayan domain komutlarını yazmak; stok komutları (T-217) bu kartları boyut alanı olarak kullanır.
**Pilot varsayımı:** A-16 (takip NONE → lot/seri ekranı yok), A-17 (SKT yok), A-20 (UNIT_ONLY → taşıma birimi akışı yok). Komutlar yine kurulur ve test edilir (04 §Takip modu kararı).
**Okuma listesi (≤5):** `docs/spec/04-data-model.md §Ürün, lot, seri, birim` (lot/seri/taşıma birimi maddeleri), `docs/adr/ADR-011.md`, `docs/OPEN_QUESTIONS.md A-72`, `packages/db/src/schema/catalog.ts` (T-204), `packages/domain/src/catalog/items.ts` (T-208 deseni)
**Dokunulacak dosyalar (≤10):** `packages/domain/src/catalog/lots.ts`, `packages/domain/src/catalog/serials.ts`, `packages/domain/src/catalog/handling-units.ts`, `packages/domain/src/catalog/traceability.test.ts`, `packages/domain/src/catalog/index.ts`, `tests/integration/catalog/traceability.int.test.ts`

**Yapılacaklar:**
1. Lot: `createLot({ itemId, lotCode, productionDate?, expiryDate?, supplierLot? })` — yalnızca `LOT`/`LOT_AND_SERIAL` ürün (aksi `TRACKING_VIOLATION`); SKT tarih-only (`YYYY-MM-DD`), üretim ≤ SKT (`VALIDATION_FAILED`); `findLot`, `listLots(itemId)` (keyset). Yetki `document.create` (lot kabulle doğar; A-45 hareket izni, A-68 kart izni değil).
2. Seri: `registerSerial({ itemId, serialNo, lotId? })` — yalnızca `SERIAL`/`LOT_AND_SERIAL` ürün; kapsam A-72 (ürün içi); `LOT_AND_SERIAL`'da lot zorunlu ve aynı ürünün lotu; tekrar → `TRACKING_VIOLATION`. Tenant geneli kapsam `SERIAL_SCOPE_TENANT_ENABLED` bayrağıyla kapalı (varsayılan kapalı; açılırsa tenant genelinde `serial_no` tekilliği komutta denetlenir — Q-39).
3. Taşıma birimi: `createHandlingUnit({ kind, code, parentId?, locationId? })`, `nestHandlingUnit(childId, parentId)` (döngü DB tetikleyicisinden gelir → `VALIDATION_FAILED`/`HANDLING_UNIT_CYCLE`), `getHandlingUnitTree`. İçerik hareketi ve koli açma 3A/3B (AC-38) — burada yok. Yetki `document.create`.
4. `index.ts` barrel'e ekleme (`package.json` değişmez; `./catalog` T-208'de).
5. Testler: `traceability.test.ts` (tarih doğrulama, mod uyumu tablosu); entegrasyon: `NONE` ürüne lot → `TRACKING_VIOLATION`, aynı seri tekrar → `TRACKING_VIOLATION`, palet→koli→palet döngüsü → `HANDLING_UNIT_CYCLE`, B tenant'ının lotu A'dan görünmez, `READ_ONLY` ile oluşturma → `FORBIDDEN`.

**Kabul ölçütü:** `pnpm verify` OK; `pnpm test:int -- traceability` PASS + tam koşu PASS.
**Kapsam dışı:** Lot/seri seçimi, FEFO, SKT uyarısı (AC-34/41, 3A koşullu), taşıma birimi hareketi (AC-38), stok satırında takip denetimi (T-217 `stock/tracking.ts`), ekran.
**Risk:** A-72 (seri kapsamı ITEM) ve lot/seri oluşturma izni (`document.create`) varsayımdır; Q-39 yanıtı tenant kapsamı isterse bayrak açılır ve DB'ye kısmi tekil indeks genişletme migration'ı gerekir.
**Gerekli inceleme:** Paket security-reviewer incelemesine dahil; bağımsız qa T-219. Paket `int/faz2-katalog`.
