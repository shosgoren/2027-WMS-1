# T-209: Bağımsız doğrulama — Faz 2 şeması: RLS/FORCE, değişmez defter, yazma koruması, NULL-safe tekillik, döngü reddi
**Faz:** 2 · **Ajan:** qa-verifier · **Bağımlılık:** T-202, T-203, T-204, T-206 (aynı int dalında) · **Dal:** `feat/T-209-qa-schema` → `int/faz2-sema`
**Amaç (tek cümle):** Uygulayıcının testlerinden bağımsız olarak Faz 2 tablolarının tenant izolasyonunu, defterin her rolde değişmezliğini, bakiyenin defter olmadan değiştirilemediğini ve ADR-011/ADR-017'deki kısıtları kanıtlamak; AC-09'un DB savunmasını etiketlemek.
**Okuma listesi (≤5):** `docs/adr/ADR-017.md`, `docs/adr/ADR-011.md §Doğrulama`, `docs/ACCEPTANCE.md AC-04, AC-09`, `docs/spec/06-operations.md §Sayım kilidi yaşam döngüsü` (ilk madde), `tests/integration/ac/ac-04-db-isolation.int.test.ts` (dinamik tablo taraması; satır 1–20, 95–135)
**Dokunulacak dosyalar (≤10):** `tests/integration/ac/ac-09-db-serial.int.test.ts`, `tests/integration/schema/stock-guard-qa.int.test.ts`, `tests/integration/schema/phase2-catalog-qa.int.test.ts`, `tests/.ac-baseline.json`

**Yapılacaklar:**
1. AC-04 (DB) mevcut dinamik test yeni tabloların tamamını kapsıyor mu: test çıktısındaki tablo listesi ≥ Faz 2 tablo kümesi (katalogdan sayılır); her biri FORCE RLS, sahibi `wms_app` değil. Eksik → FAIL (test değiştirilmez; eksik fikstür bulgusu ilgili migration kartına iade).
2. `stock-guard-qa`: (a) `wms_app` ile defter satırı olmadan bakiye `quantity` artışı → commit'te ret; (b) defter satırı + uyumsuz bakiye farkı → ret; (c) uyumlu defter + bakiye aynı transaction → kabul; (d) defter UPDATE/DELETE/TRUNCATE `wms_app`, `wms_ops`, migration rolü ve `session_replication_role=replica` altında → ret; (e) `reserved_quantity` ≠ ACTIVE rezervasyon toplamı → ret; (f) `wms_app`/`wms_ops` stok tablosunda DELETE → 42501.
3. `phase2-catalog-qa`: NULL lot/seri/sahip/taşıma birimi içeren iki özdeş boyut → tekillik reddi (ADR-011 riski); taşıma birimi döngüsü (A→B→C→A) → ret; lokasyon `parent_id` güncellemesi → ret; yeni lokasyonun kilit satırı aynı transaction'da var ve rollback'te yok; `location_count_locks` DELETE → ret; `POSTED` belge satırı değişimi → ret.
4. AC-09 (DB katmanı): seri boyutunda miktar 2 → CHECK reddi; aynı seri iki lokasyonda pozitif → tekil indeks reddi. Başlık `@AC-09`, dosya başı "katman: DB (komut katmanı T-220)".
5. Migration ileri → geri → ileri döngüsü süper kullanıcı olmayan migrator ile (mevcut `migrations-nonsuper` koşusunun 0010–0012'yi kapsadığını doğrula; kapsamıyorsa bulgu, test değiştirilmez).
6. `pnpm check:ac-ratchet --update`.

**Kabul ölçütü:** `pnpm test:int -- ac-09 stock-guard-qa phase2-catalog-qa` PASS; `pnpm test:ac -- AC-09` → yeni testler sayılır (sayı rapora); `pnpm test:ac -- AC-04` PASS; `pnpm verify` OK; `pnpm check:all` OK.
**Kapsam dışı:** Komut düzeyi davranış (T-220), kuyruk tabloları (T-218).
