# T-008c: `check:protected` — korunan dosya + insan onayı doğrulaması (AC-43 birim düzeyi)
**Faz:** 0 · **Ajan:** devops · **Bağımlılık:** T-008a (T-008b ile paralel) · **Dal:** `feat/T-008c-check-protected` → `int/faz0-bekciler-1`
**protected: true** (beyan; onay değildir) — bekçi betiği + korunan yol listesi.
**Amaç (tek cümle):** Korunan yol değişikliğinde PR açıklamasında ADR-012 rev. onay satırlarının (`APPROVED-BY: supervisor (ADR-012 rev.)` + BLOCKER: 0 güvenlik raporu özeti) bulunduğunu GitHub API'den doğrulayan, doğrulayamazsa kırmızı dönen `pnpm check:protected`'ı yazmak.
**Okuma listesi (≤5):** `docs/agents/PROTOCOL.md §3b` (`check:protected` satırı) + `§Onay kaynağı`, `docs/INVARIANTS.md I-17`, `docs/ACCEPTANCE.md AC-43`, `docs/adr/ADR-012.md`, `scripts/guards/lib/git.mjs` + `lib/testkit.mjs`
**Dokunulacak dosyalar (≤10):** `scripts/guards/protected.mjs`, `scripts/guards/protected-paths.mjs`, `scripts/guards/lib/github.mjs`, `scripts/guards/lib/approval.mjs`, `scripts/guards/protected.test.mjs`, `scripts/guards/lib/approval.test.mjs`, `tests/guards/ac-43.test.mjs`
> **Revizyon 2026-10-05 (ADR-012 rev.):** CODEOWNERS/insan incelemesi doğrulaması kaldırıldı; onay kaynağı PR açıklamasındaki satırlardır. Bilinen risk ADR-012'de.

**Yapılacaklar:**
1. `protected-paths.mjs` (tek kaynak): PROTOCOL §3b listesi — `docs/INVARIANTS.md`, `docs/ACCEPTANCE.md`, `docs/spec/16-stock-effects.md`, `packages/db/src/locking.mjs`, `main`'de var olan migration dosyaları (değişiklik/silme; yeni migration korunmaz), `.github/**`, lint/tsconfig/test yapılandırmaları (`eslint.config.mjs`, `**/tsconfig*.json`, `vitest.config.*`, `playwright.config.*`), `scripts/verify.mjs`, `scripts/check-docs.mjs` (T-004), `scripts/guards/**`, `scripts/test-ac/**`, `scripts/lib/**`, `.githooks/**`, kök `package.json`'da ORM/sürücü/pooler sürüm alanları ve compose'daki pooler imaj etiketi; `pnpm-workspace.yaml`, `.npmrc` ve tüm `package.json`'larda audit yapılandırması (`auditConfig`) — T-003 security-reviewer MAJOR. §Onay kaynağı listesinden türeyenler: `tests/.ac-baseline.json` (yalnızca **düşüş**; artış serbest), `tests/QUARANTINE.md`, `docs/ACCEPTANCE.conditions.json`, `docs/DECISIONS.md` ve `docs/adr/ADR-*.md`'de durumun "kabul"e geçmesi. Gerçek yollar repoda grep'lenir; yoksa desen olarak kalır (G-05).
2. `lib/github.mjs`: `fetch` ile (yeni bağımlılık yok) PR gövdesi (`body`) ve head SHA; `GITHUB_TOKEN`/`GITHUB_REPOSITORY`/PR no ortamdan (GitHub REST alan adları belgeden doğrulanır, G-04). Arayüz enjekte edilebilir (test çifti yalnızca testte; G-07).
3. `lib/approval.mjs` kuralı: korunan değişiklik varsa PR gövdesinde (a) tam satır `APPROVED-BY: supervisor (ADR-012 rev.)` ve (b) `security-reviewer` rapor özeti satırı `security-reviewer: BLOCKER: <n> · MAJOR: <n> · MINOR: <n>` bulunmalı ve `n(BLOCKER) == 0`. Karttaki `protected: true` hiçbir koşulu karşılamaz.
4. Fail-closed: API erişimi yoksa veya CI'da PR bağlamı yoksa → FAIL `APPROVAL_UNVERIFIABLE`. `main`'e push koşusunda (PR yok) birleşmiş PR'ın gövdesi commit'ten bulunur (`GET /repos/{o}/{r}/commits/{sha}/pulls`); bulunamazsa FAIL. Yerel kanca modu (`--local`) yalnızca uyarır `PROTECTED_CHANGE_NEEDS_APPROVAL` (çıkış 0).
5. Neden kodları: `PROTECTED_NO_APPROVAL` (APPROVED-BY yok), `SECURITY_REPORT_MISSING`, `SECURITY_BLOCKER`, `APPROVAL_UNVERIFIABLE`; dosya yolu ile.
6. Korunan dosya ilk oluşturma akışı T-007 Yapılacaklar 6 ile aynı.

**Kabul ölçütü:** `pnpm vitest run scripts/guards/protected.test.mjs scripts/guards/lib/approval.test.mjs tests/guards` yeşil. `tests/guards/ac-43.test.mjs` başlıkları `@AC-43` taşır ve AC-43'ün dört kırmızı durumunu (yalnızca kart beyanı, rapor yok, BLOCKER > 0, APPROVED-BY yok) ayrı ayrı FAIL + doğru neden kodu, iki satır birlikte + BLOCKER 0 durumunu OK olarak doğrular; ayrıca API yok → FAIL, baseline artışı → korunan sayılmaz, düşüşü → korunan. `pnpm test:ac -- AC-43` PASS. Canlı GitHub kanıtı T-009b'de. `pnpm verify` özeti raporda.
