# T-204: Migration 0011 — katalog ve izlenebilirlik tabloları (birim, ürün, dönüşüm, barkod, sahip, lot, seri, taşıma birimi)
**Faz:** 2 · **Ajan:** db-engineer · **Bağımlılık:** T-202 (`int/faz2-sema`'da) · **Dal:** `feat/T-204-catalog-schema` → `int/faz2-sema`
**Amaç (tek cümle):** Pilot takip modu ne olursa olsun (04 §Takip modu kararı, ADR-011) ürün/birim/barkod kartlarını ve lot, seri, stok sahibi, taşıma birimi tablolarını RLS şablonu, NULL-safe tekillik ve döngü reddiyle kurmak.
**Pilot varsayımı:** A-16 (takip NONE), A-20 (UNIT_ONLY), A-22 (tek sahip), A-32/A-33 (ADET, 0 ondalık) — model bunlardan bağımsız kurulur; yalnızca varsayılanlar etkilenir.
**Okuma listesi (≤5):** `docs/spec/04-data-model.md §Ürün, lot, seri, birim`, `docs/adr/ADR-011.md`, `docs/adr/ADR-017.md §1, §9`, `docs/OPEN_QUESTIONS.md A-69, A-72`, `packages/db/migrations/0010_warehouses_locations.up.sql` (T-202 deseni)
**Dokunulacak dosyalar (≤10):** `packages/db/migrations/0011_catalog_traceability.up.sql`, `packages/db/migrations/0011_catalog_traceability.down.sql`, `packages/db/src/schema/catalog.ts`, `packages/db/src/schema/index.ts`, `packages/db/src/index.ts`, `tests/integration/fixtures/tenants.ts`, `tests/integration/schema/catalog-schema.int.test.ts`

**Yapılacaklar:**
1. `units (tenant_id, id, code, name, status)` `UNIQUE (tenant_id, code)`. `items (tenant_id, id, code, name, base_unit_id, tracking_mode NONE|LOT|SERIAL|LOT_AND_SERIAL, quantity_scale smallint CHECK 0..6, pick_policy FIFO|FEFO, status ACTIVE|ARCHIVED, …)` `UNIQUE (tenant_id, code)`; FK `(tenant_id, base_unit_id)`.
2. `unit_conversions (tenant_id, id, item_id, unit_id, to_base_factor numeric(20,6) CHECK (> 0))` `UNIQUE (tenant_id, item_id, unit_id)`; temel birim için satır yok (katsayı 1 örtük).
3. `item_barcodes (tenant_id, id, item_id, unit_id NULL, barcode, quantity numeric(20,6) NULL)`; `UNIQUE NULLS NOT DISTINCT (tenant_id, item_id, unit_id, barcode)`; `(tenant_id, barcode)` üzerinde **benzersiz olmayan** indeks (belirsizlik komutta çözülür, A-69).
4. `inventory_owners (tenant_id, id, code, name)` — Faz 2'de satır üretilmez; boyutta NULL = tenant'ın kendi stoku (ADR-017 §1).
5. `lots (tenant_id, id, item_id, lot_code, production_date date NULL, expiry_date date NULL, supplier_lot NULL)` `UNIQUE (tenant_id, item_id, lot_code)`. `serials (tenant_id, id, item_id, serial_no, lot_id NULL)` `UNIQUE (tenant_id, item_id, serial_no)` (A-72 kapsam ITEM). Ürüne bağlı bileşik FK hedefleri (ADR-017 §2, M-3): `lots UNIQUE (tenant_id, item_id, id)`, `serials UNIQUE (tenant_id, item_id, id)`; seri → lot FK `(tenant_id, item_id, lot_id) → lots (tenant_id, item_id, id)` (başka ürünün lotu reddedilir). Tüm FK'ler `(tenant_id, …)` bileşik: `items.base_unit_id`, `unit_conversions (item, unit)`, `item_barcodes (item, unit)`, `handling_units (parent, location)`.
6. `handling_units (tenant_id, id, kind KOLI|PALET, code, parent_id NULL, location_id NULL, status OPEN|CLOSED|EMPTIED)` `UNIQUE (tenant_id, code)`; `CHECK (parent_id <> id)`; `parent_id` değişebileceği için (palete koli ekleme) `BEFORE INSERT OR UPDATE OF parent_id` tetikleyicisi özyinelemeli ata taramasıyla döngüyü reddeder (`HANDLING_UNIT_CYCLE` mesaj tanımlayıcısıyla, SQLSTATE `23514`).
7. RLS/FORCE/GRANT (T-202 deseni); arşiv: `items`, `units`, `lots` DELETE yetkisi yok. Drizzle şeması + sapma; `seedWorld` her yeni tablo için A ve B satırı.
8. `catalog-schema.int.test.ts`: NULL birimli iki aynı barkod satırı → tekillik reddi; aynı barkod iki ürüne → kabul (A-69); dönüşüm katsayısı 0/negatif → ret; A→B→A taşıma birimi döngüsü → ret; aynı ürün içinde seri tekrarı → ret, farklı üründe aynı seri → kabul.

**Kabul ölçütü:** `pnpm verify` OK; `pnpm test:int` tam koşu PASS (AC-04 DB, drift, migrations dahil).
**Kapsam dışı:** Belgeler (T-206), stok boyutları/defter (T-232), domain komutları (T-208, T-212), min-maks politikası (`item_stock_policies`, 3A AC-20).
**Risk:** `UNIQUE NULLS NOT DISTINCT` PG 15+ ister (yerel/CI/Neon PG 18 — Q-05; kurulu sürümde doğrula, G-04). Taşıma birimi döngü tetikleyicisi eşzamanlı iki `nest` işleminde yarışabilir → tetikleyici ilgili ata zincirini `FOR UPDATE` kilitler; testte iki eşzamanlı çapraz iç içe koyma.
**Gerekli inceleme:** security-reviewer zorunlu (RLS); bağımsız qa T-209. Paket `int/faz2-sema`.
