1. Kod önerisi: yeni ürün/depo/lokasyon formunda sıradaki kod hazır gelir (önek + sıra; tenant içinde benzersizlik sunucuda yeniden denetlenir, çakışmada bir sonraki öneri); kullanıcı değiştirebilir (A-xx önek biçimi).
2. Toplu raf oluşturucu: "Bölge A, raf 1–10, göz 1–5" → önizleme (kaç lokasyon, örnek kodlar) → tek komutla oluşturma; tek transaction, üst sınır (A-07 benzeri, ör. 2.000), yetki `location.manage`, idempotency anahtarı; mevcut kodla çakışma → oluşturmadan önce listelenir.
3. Akıllı varsayılanlar: birim ADET, ondalık 0, takip yok, FIFO önceden seçili; gelişmiş ayarlar kapalı bölümde (sektör şablonu değerleri öncelikli).
4. Yazdıkça arama: ürün/lokasyon seçicileri ilk harflerde öneri listesi (sunucu araması, sınırlı sonuç, klavye + 48 px dokunma), barkod okutunca doğrudan seçim (ScanField, T-303).
