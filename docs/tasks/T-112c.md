**Okuma listesi (≤5):** `packages/db/migrations/0002_identity.up.sql` (security_events yetkileri ve tetikleyicileri), `packages/db/src/audit.ts` (`recordSecurityEvent` — `INSERT … RETURNING`), `packages/auth/src/index.ts` (`emit`/`eventClient`), `docs/adr/ADR-014.md` §14, `docs/adr/ADR-016.md` §1
**Dokunulacak dosyalar (≤10):** `packages/db/migrations/0005_security_event_writers.up.sql`, `packages/db/migrations/0005_security_event_writers.down.sql`, `packages/db/src/audit.ts`, `packages/db/src/audit.test.ts`, `packages/auth/src/index.ts`, `tests/integration/auth/auth-events.int.test.ts`, `tests/integration/schema/drift.int.test.ts`

**Yapılacaklar:**
1. 0005: `security_events` BEFORE INSERT tetikleyicisi (ENABLE ALWAYS, SECURITY INVOKER): `event_type` kimlik sınıfındaysa (`reauth.`, `login_`, `session.`, `mfa.`, `password.` önekleri — kesin liste T-112'deki emit çağrılarından grep'le) `current_user = 'wms_auth'` şart; değilse 42501. Uygulama sınıfı olaylar `wms_app` ile sürer.
2. `wms_auth`'a `security_events` üzerinde yalnızca gerekli sütunlarda INSERT (T-102'deki sütun listesi) — `RETURNING id` için SELECT gerekmeyecek biçimde `recordSecurityEvent`'e `returning: false` yolu ya da istemci tarafı UUID (sunucu `id` varsayılanını zorlayan tetikleyiciyle uyumlu olmalı — T-102 tetikleyicisi istemci `id`'sini reddediyor; ona uygun yol seç ve gerekçele).
3. `packages/auth` olayları `wms_auth` istemcisiyle (maskedDb üzerinden) yazsın; `eventClient` (wms_app) kimlik olayları için kaldırılsın.
4. Testler: wms_app ile `reauth.succeeded`/`login_succeeded` INSERT → 42501; wms_auth ile → OK; uygulama sınıfı olay wms_app ile → OK; ileri/geri/ileri (süper kullanıcı olmayan migrator testi varsa onda da; down veri kaybı bekçisi FORCE RLS dersine uygun).
5. Migration numarası 0005 (0004 T-107; 0006 T-115'e ayrılmıştı ama kullanılmadı).
