**Yapılacaklar:**
1. `counts`: oturum listesi (durum, lokasyon sayısı, başlama zamanı, terk süresi aşıldıysa uyarı rozeti) + başlatma formu (lokasyon ağacından çoklu seçim veya açık `COUNT` görevinden; kör sayım anahtarı). Başlatma reddinde "Lokasyonda süren işlem var / zaten sayımda: <kodlar>" (kısmi kilit olmadığı açık yazılır).
2. Saha sayım: lokasyon okut → ürün okut (koli → adet) → sayılan miktar; kör sayımda referans miktar gösterilmez; aynı lokasyonda sayılmayan ürün = 0 onayı ("Bu lokasyonda başka ürün yok" düğmesi).
3. Gözden geçirme (`counts/[id]`): lokasyon × ürün referans / sayılan / fark; "Onayla" (`count_diff.approve`) → "Fark fişini işle" (tek adımda zincir, iki ayrı komut; ilk başarılı ikinci başarısızsa durum ekranda "onaylandı, fiş bekliyor"); "İptal" (gerekçe zorunlu, "fark uygulanmayacak, kilit açılacak").
4. Yetkisiz eylemler kilitli + açıklama; anahtar yaşam döngüsü T-313 ile aynı.
5. `actions.test.ts`: zincirde ikinci adım hatası durumu, hata eşlemesi (`LOCATION_LOCKED`, `DOCUMENT_STATE`, `FORBIDDEN`), decimal iletimi.
