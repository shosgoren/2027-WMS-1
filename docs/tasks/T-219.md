# T-219: Bağımsız doğrulama — katalog ve izlenebilirlik komutları, decimal dönüşüm, barkod belirsizliği, AC-04 eylem katmanı
**Faz:** 2 · **Ajan:** qa-verifier · **Bağımlılık:** T-208, T-212, T-216 (aynı int dalında) · **Dal:** `feat/T-219-qa-catalog` → `int/faz2-katalog`
**Amaç (tek cümle):** Ürün/birim/barkod/lot/seri/taşıma birimi komutlarının tenant izolasyonunu, decimal dönüşümün float'sız ve belge satırına kopyalanmaya uygun olduğunu (I-09), belirsiz barkodun sessizce atanmadığını ve ADR-011 döngü reddini bağımsız testlerle kanıtlamak.
**Okuma listesi (≤5):** `docs/ACCEPTANCE.md AC-04`, `docs/spec/04-data-model.md §Ürün, lot, seri, birim`, `docs/INVARIANTS.md I-09`, `packages/domain/src/catalog/index.ts`, `tests/integration/ac/ac-04-api-slug.int.test.ts` (eylem listesi deseni)
**Dokunulacak dosyalar (≤10):** `tests/integration/ac/ac-04-api-slug-catalog.int.test.ts`, `tests/integration/catalog/catalog-qa.int.test.ts`, `tests/unit/catalog/quantity-property.test.ts`, `tests/.ac-baseline.json`

**Yapılacaklar:**
1. AC-04 (API — sayfa/eylem): A oturumuyla `/t/<B-slug>/items` ve B slug'lı her ürün/birim/barkod Server Action'ı → `NOT_FOUND`; A slug'ında B'nin `itemId`/`unitId`'si ile `addBarcode`/`setUnitConversion` → `NOT_FOUND` (varlık sızmaz). `@AC-04`, "katman: API (sayfa/eylem)".
2. Barkod: aynı barkod iki üründe → çözümleme `BARCODE_AMBIGUOUS`, aday listesinde yalnızca A tenant'ının kayıtları; B'de aynı barkod A'yı etkilemez. GS1: geçersiz kontrol haneli GTIN → ret; FNC1'siz değişken uzunluk sonu doğru.
3. Decimal (I-09): `quantity-property.test.ts` — `toBase(qty, factor, scale)` için rastgele ölçekli değerlerde (test içi üreteç; fast-check T-220'de eklenir, burada kullanılmaz) tersine çevrilebilirlik ve ölçek reddi; `0.1 + 0.2` türü float hatası yok.
4. İzlenebilirlik: `NONE` ürüne lot/seri → `TRACKING_VIOLATION`; ürün içi seri tekrarı → ret, farklı üründe kabul (A-72); taşıma birimi döngüsü → `HANDLING_UNIT_CYCLE`; stoklu üründe takip modu değişimi → `IN_USE` (fikstür: migration rolüyle defter + bakiye).
5. `pnpm check:ac-ratchet --update`.

**Kabul ölçütü:** `pnpm test:int -- ac-04-api-slug-catalog catalog-qa` PASS; `pnpm verify` OK (birim testi dahil); `pnpm test:ac -- AC-04` sayısı arttı; `pnpm check:all` OK.
