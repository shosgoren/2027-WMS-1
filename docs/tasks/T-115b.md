# T-115b: Worker imajı — workspace paketleri ve pg-boss ile çalışan runtime aşaması
**Faz:** 1 · **Ajan:** devops · **Bağımlılık:** T-115 · **Dal:** `feat/T-115b-worker-image` → `int/faz1-auth`
**Amaç (tek cümle):** `Dockerfile` runtime aşamasının yalnızca `apps/worker/dist` kopyalaması yüzünden çalışmayan worker'ı (workspace `.ts` paketleri `@wms/queue-adapter`, `@wms/shared` ve `pg-boss` çözülemiyor — T-115 bulgu 1) üretimde çalışır hale getirmek.
**Okuma listesi (≤5):** `Dockerfile`, `apps/worker/package.json`, `apps/worker/tsconfig.build.json`, `fly.staging.toml` (worker süreç grubu), `docs/adr/ADR-013.md`
**Dokunulacak dosyalar (≤10):** `Dockerfile`, `apps/worker/package.json`, `apps/worker/tsconfig.build.json`, `.dockerignore`, `scripts/deploy-smoke.mjs`, `docs/STACK.md`

**Yapılacaklar:**
1. Seçenek A (tercih): `pnpm deploy --filter @wms/worker --prod` ile yalıtılmış üretim bağımlılık ağacı + workspace paketlerinin derlenmiş çıktısı; seçenek B: tek dosya bundle (esbuild — yeni bağımlılık, tam sürüm + STACK). G-04: kurulu pnpm sürümünde `deploy` davranışını doğrula.
2. İmajda geliştirme bağımlılığı ve kaynak `.ts` yok; root olmayan kullanıcı; `--ignore-scripts` korunur.
3. Yerel kanıt: `docker build` + compose ağında worker başlatma → "kuyruk başlatıldı" log satırı; SIGTERM ile temiz kapanış.
4. `deploy-smoke.mjs`: staging'de worker süreç grubunun ayakta olduğunu denetleyen adım (varsa mevcut desene uygun).

**Kabul ölçütü:** `docker build` OK; yerel worker log kanıtı; `pnpm verify` OK; imaj boyutu rapora.
**Gerekli inceleme:** security-reviewer (imaj içeriği, sırlar). Paket `int/faz1-auth`.

**Supervisor eki (inceleme @1582f66):** `pnpm-lock.yaml` (korunan) dokunulacak dosyalara eklendi — esbuild devDependency'si için `--frozen-lockfile` gereği; esbuild'in vite opsiyonel peer'i olarak çözülmesi kabul edilen yan etki (sürüm STACK'te sabit). Yapılacaklar 4 (`deploy-smoke.mjs` worker süreç grubu denetimi) eksik — tamamlanacak. Ek kabul: build sonrası `node apps/worker/dist/main.js` (DB ortamı olmadan) stderr'inde `MIGRATION_` öneki görülmez; bunu build kontrol adımına ekle. Bilinen risk (MINOR-1): bundle'daki dinamik `require` imajdaki `/app/node_modules` (web ağacı) üzerinden çözülür — bugün yalnızca Node yerleşikleri; worker'a yerel olmayan dinamik require eklenirse `--external` listesi + imaj denetimi gerekir.

**Supervisor eki (2026-10-06, dilim birleştirme):** hedef dal `int/faz1-kuyruk-eposta` yerine `int/faz1-auth`. Gerekçe: T-113 T-115 üzerine yığıldı (packages/shared ortak tabanı); kuyruk ve kimlik dilimleri tek paket olarak main'e gider, ayrı int dalı yaratılmadı.
