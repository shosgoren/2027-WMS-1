# T-003: CI hattı (GitHub Actions) — verify + compose duman + sır/bağımlılık taraması
**Faz:** 0 · **Ajan:** devops · **Bağımlılık:** T-002a–d (`int/faz0-iskelet` birleşmiş) · **Dal:** `feat/T-003-ci` → `int/faz0-ci`
**Amaç (tek cümle):** Her PR'da ve `main`/`int/**` push'unda `pnpm verify`, docker compose (PgBouncer transaction mode dahil) duman testi, sır taraması ve bağımlılık denetimini koşturan CI tanımını kurmak.
**Okuma listesi (≤5):** `docs/spec/14-reliability-ops.md` (CI maddesi), `docs/agents/PROTOCOL.md §3b`, `docs/adr/ADR-012.md §Mevcut durum`, `docs/tasks/T-002a.md`, `docs/tasks/T-002d.md`
**Dokunulacak dosyalar (≤10):** `.github/workflows/ci.yml`
**protected: true** — CI tanımı korunan dosyadır (`14`, PROTOCOL §3b). Ayrı küçük PR; kullanıcı GitHub'da inceleyip **kendisi birleştirir** (ADR-012 geçici dönem). Ajanın beyanı onay değildir.

**Yapılacaklar:**
1. Tetikleyiciler: `pull_request`, `push` (`main`, `int/**`); `concurrency` ile aynı dalda eski koşu iptal; `permissions: contents: read`; bu iş akışında **sır kullanılmaz** (Neon koşusu T-005d, CI'a girmez).
2. Üçüncü taraf action'lar **tam commit SHA** ile sabitlenir (etiket yorumda); Node sürümü `package.json engines`'ten, pnpm `packageManager`'dan; `pnpm install --frozen-lockfile`.
3. İş `verify`: `pnpm verify`; `.artifacts/` artefakt olarak yüklenir (başarısızlıkta da).
4. İş `infra`: `cp .env.example .env` → `docker compose up -d --wait` → `pnpm infra:smoke` → başarısızlıkta `docker compose logs` artefakt → her durumda `docker compose down -v`.
5. İş `secrets`: sır tarayıcı (aday gitleaks; lisans ve bakım durumu doğrulanıp rapora); bulgu → kırmızı.
6. İş `deps`: `pnpm audit` — eşik **high ve critical = kırmızı** (öneri; rapora "A-öneri" olarak yazılır, Supervisor `A-xx`'e çevirir); lisans denetimi (GPL/AGPL doğrudan bağımlılık = kırmızı).
7. Yer tutucu iş/adım **eklenmez** (`check:all` → T-008, `test:ac` → T-007, `test:int` PgBouncer katmanı → T-005a, migration ileri/geri → ilk migration kartı, Playwright → Faz 1). Her biri kendi kartında korunan değişiklik olarak eklenir; "boş yeşil adım" sahte başarıdır (G-07).
8. İş adları sabit ve rapora yazılır: T-009 bunları branch protection'da zorunlu durum kontrolü yapar.

**Kabul ölçütü:**
- Bu dalın PR'ında dört iş (`verify`, `infra`, `secrets`, `deps`) yeşil — koşu bağlantısı rapora.
- Negatif kanıt: birleştirilmeyecek deneme dalı `ci-probe/T-003-lint` (tek satır lint hatası) → `verify` kırmızı; `ci-probe/T-003-pool` (`pool_mode = session`) → `infra` kırmızı. İki koşu bağlantısı rapora; deneme dalları PR'a dönüşmez.
- `actionlint` (veya eşdeğeri) yerelde `ci.yml` için hatasız — çıktı özeti rapora.
**Kapsam dışı:** Branch protection/CODEOWNERS (T-009), bekçiler (T-008), `test:ac` (T-007), `test:int` (T-005a), deploy, Neon sırları.
**Gerekli inceleme:** Risk matrisi: sır/haricî entegrasyon (CI izinleri, action sabitleme) → **security-reviewer zorunlu**; qa: uygulayıcının negatif kanıtları yeterli. Korunan dosya → kullanıcı onayı (PROTOCOL §Onay kaynağı).
