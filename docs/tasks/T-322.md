# T-322: Niyet (intent) katmanı — sözleşme, tek sunucu dağıtıcısı, önizleme + tek onay
**Faz:** 3A · **Ajan:** backend-dev (+ ince web bileşeni) · **Bağımlılık:** ADR-023 (öneri → kabul), T-213 (`runTenantCommand` deseni, main), T-262 (ADR-024 onay/geri al politikası; yalnız atıf) · **Dal:** `feat/T-322-intent-layer` → `int/faz3a`
**Amaç (tek cümle):** Dokunuş, ses ve ileride AI'ın aynı yoldan çalışması için niyet sözleşmesini (`IntentId` + Zod şeması + izin + okuma/yazma + dokunuş bütçesi) ve iş mantığı içermeyen tek sunucu dağıtıcısını, yazma niyetlerinde yan etkisiz önizleme + parmak izli tek onayla kurmak.
**Okuma listesi (≤5):** `docs/adr/ADR-023.md §Karar 1–3`, `apps/web/lib/action-guard.ts` (`createActionGuard`, 117–175), `packages/domain/src/identity/permissions.ts`, `packages/domain/src/audit/today.ts` (`listMyActionsToday`), `packages/shared/src/errors.ts`
**Dokunulacak dosyalar (≤10):** `packages/shared/src/intents.ts` (yeni), `packages/shared/src/intents.test.ts` (yeni), `packages/shared/package.json`, `apps/web/lib/intents/dispatch.ts` (yeni), `apps/web/lib/intents/dispatch.test.ts` (yeni), `apps/web/lib/intents/handlers.ts` (yeni), `apps/web/app/t/*/intent-actions.ts` (yeni), `apps/web/app/t/*/intent-preview.tsx` (yeni), `apps/web/messages/tr.json`, `apps/web/messages/en.json`

**Yapılacaklar:**
1. `intents.ts`: `IntentId` kapalı birleşim (bu kartta: `orders.today`, `actions.today`, `nav.open`; diğer kimlikler yalnız tip olarak, işleyicisi yoksa dağıtıcı `FEATURE_DISABLED`), `IntentDef { kind, params: ZodType, permission, touchBudget }`, `INTENTS` tablosu. İş mantığı ve DB erişimi yok. Test: her tanımın şeması örnek geçerli/geçersiz girdiyle; `permission` değeri `permissions.ts` kümesinde; `touchBudget` UX_NOVICE §6 tablosuyla aynı (tablo sabit olarak testte).
2. `dispatch.ts`: `runIntent({ intent, params, phase, fingerprint?, clientKey? }, deps)` — bilinmeyen niyet → `VALIDATION_FAILED`; Zod hatası → `VALIDATION_FAILED`; okuma niyeti `phase` yok sayar; yazma niyetinde `preview` işleyicinin `preview` ucunu, `confirm` `fingerprint` + `clientKey` zorunlu (`IDEMPOTENCY_KEY_REQUIRED`) olarak `execute` ucunu çağırır. Test: önizleme çağrısında `execute` 0 kez çağrılır (sahte işleyici sayacı); `confirm` parmak izi eksik → `VALIDATION_FAILED`; işleyicinin `VERSION_CONFLICT`'i aynen döner.
3. `handlers.ts`: işleyici kaydı — `actions.today` → `listMyActionsToday`; `nav.open` → izinli ekran anahtarından yol (beyaz liste, serbest URL yok — `safe-redirect.ts` deseni); `orders.today` işleyicisi T-325 gelene kadar kayıtsız (`FEATURE_DISABLED`, sahte veri yok). Test (`dispatch.test.ts` içinde): `nav.open` beyaz liste dışı anahtar → `VALIDATION_FAILED`.
4. `intent-actions.ts` (`"use server"`): `runIntentAction` — `createProductionGuard` ile sarılır; dağıtıcıya yalnız doğrulanmış tenant/üyelik bağlamını geçirir; hata gövdesine parametre değerleri yazılmaz (G-09). Test: `dispatch.test.ts`'te guard'sız çağrının reddi (bağımlılık enjeksiyonuyla).
5. `intent-preview.tsx`: önizleme sayfası/çekmecesi — özet satırları, uyarılar, tek birincil düğme ("Onayla", ADR-023 §3), "Vazgeç"; `VERSION_CONFLICT`'te "Durum değişti, yeni öneri hazır" + otomatik yeni önizleme. 48 px, tek birincil eylem (K-04). Test: `dispatch.test.ts` kapsamındaki durum makinesi saf işlevi (`previewState`) — onay düğmesi yalnız `ready` durumunda etkin.
6. `messages/*.json`: `intents.*` anahtarları (TR/EN eşit anahtar kümesi — mevcut i18n testi).

**Kabul ölçütü:** `pnpm verify` OK; `pnpm --filter @wms/web build` OK; `intents.test.ts` + `dispatch.test.ts` PASS; `check:all` yeşil.
