**Yapılacaklar:**

2. `migrate.ts`'e dokunma (izin listesi gevşetilmez, G-11).
3. Normalize edilmiş URI maskelenir; özete yalnızca "uri normalize: channel_binding kaldırıldı, sslmode=verify-full" satırı (değer yok).
4. Testler: Neon biçimli URI (channel_binding + sslmode=require) → verify-full, channel_binding yok; `options=` içeren URI → hata; zaten uygun URI değişmez; maskeleme. Literal sır yok.
