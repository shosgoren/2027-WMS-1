# T-002a: Kök pnpm çalışma alanı + araç zinciri + `pnpm verify`
**Faz:** 0 · **Ajan:** devops · **Bağımlılık:** T-001 (ADR-001/002/003 önerildi) · **Dal:** `feat/T-002a-workspace-verify` → `int/faz0-iskelet`
**Amaç (tek cümle):** Boş repoyu, `pnpm verify` ile lint+typecheck+unit koşturan ve yalnızca hata özetini basan pnpm monorepo köküne çevirmek.
**Okuma listesi (≤5):** `docs/adr/ADR-001.md §Karar`, `docs/adr/ADR-002.md §Karar`, `docs/STACK.md`, `docs/spec/15-engineering.md §Kod, §Test stratejisi`, `.claude/agents/devops.md`
**Dokunulacak dosyalar (≤10):** `package.json`, `pnpm-workspace.yaml`, `pnpm-lock.yaml`, `.gitignore`, `tsconfig.json`, `eslint.config.mjs`, `vitest.config.ts`, `scripts/verify.mjs`, `scripts/verify.test.mjs`
**protected: true** (beyan: tsconfig/lint/test yapılandırması korunan dosyadır; T-009 öncesi `main`'e yalnızca kullanıcı birleştirir — ADR-012)

**Yapılacaklar:**
1. `pnpm-workspace.yaml`: `apps/*`, `packages/*`. Paket kapsamı **`@wms/*`** (ürün adı Q-08 açık; "rafta"/"stoklu" paket adına girmez).
2. Kök `package.json`: `private`, `packageManager` (kurulu pnpm), `engines.node` = güncel Node.js **Active LTS** ana sürümü (nodejs.org sürüm takviminden doğrula, G-04). Bağımlılıklar `pnpm add -E` ile **tam sürüm**.
3. Dev bağımlılıkları yalnızca `typescript`, `eslint`, `typescript-eslint`, `vitest`, `@types/node`; her biri için lisans (GPL/AGPL değil) ve son yayın tarihi rapora.
4. `tsconfig.json` (taban): `strict`, `noUncheckedIndexedAccess`, `allowJs`+`checkJs`; kendi `include`'u `scripts/**/*.mjs`. Uygulama/paketler bunu `extends` eder ve kendi `typecheck` betiğini tanımlar.
5. `eslint.config.mjs` (flat config, typescript-eslint); tüm repo; `no-explicit-any` = error (15 §Kod "gerekçeli" → satır içi disable + gerekçe).
6. `vitest.config.ts`: unit; include `**/*.test.{ts,tsx,mjs}`; exclude `**/*.int.test.ts`, `tests/integration/**`, `node_modules`, `.next`, `dist` (entegrasyon = `test:int`, T-005a; `*.int.test.ts` adlandırması sabittir).
7. `scripts/verify.mjs`: lint (kök eslint) → typecheck (kök `tsc --noEmit` + `pnpm -r --if-present run typecheck`) → unit (kök vitest) sırayla; tam çıktı `.artifacts/verify/<adım>.log`; konsola yalnızca ilk 10 hata (dosya:satır + mesaj) ve **tek özet satırı** `verify: lint OK|FAIL · typecheck OK|FAIL · unit OK|FAIL (<n> test)`; FAIL → çıkış ≠ 0. Özetleyici fonksiyon dışa aktarılır, `verify.test.mjs` onu birim test eder (OK/FAIL, hata kesme, n sayısı).
8. `.gitignore`: `node_modules`, `.next`, `dist`, `.artifacts/`, `.env`, `.env.*` (`!.env.example`).

**Kabul ölçütü:**
- `pnpm install --frozen-lockfile && pnpm verify` → özet satırında üç adım OK, çıkış 0, unit test sayısı ≥1.
- Negatif kanıt: `scripts/verify.mjs`'e geçici JSDoc tip hatası → `typecheck FAIL`, çıkış ≠ 0, özet dosya:satır gösterir; geri alınır. İki çıktının özet satırı rapora.
- `git diff --stat` yalnızca yukarıdaki 9 dosya.
**Kapsam dışı:** `apps/*` (T-002b/c), docker compose (T-002d), `packages/db` (T-005b), `packages/shared|domain|ui` (ilk kullanan kart açar; boş paket açılmaz), Tailwind/next-intl, CI (T-003), STACK.md (T-004).
**Gerekli inceleme:** Risk matrisi "Diğer" → security-reviewer gerekmez; uygulayıcının testleri yeterli. Paket `int/faz0-iskelet` (T-002a–d) Supervisor incelemesi + kullanıcı birleştirmesi.
