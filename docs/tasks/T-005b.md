# T-005b: `packages/db` — Drizzle istemcisi + `withTenant` + global istemci lint yasağı + RLS sonda fikstürü
**Faz:** 0 · **Ajan:** backend-dev · **Bağımlılık:** T-005a · **Dal:** `feat/T-005b-with-tenant` → `int/faz0-pooler`
**Amaç (tek cümle):** Tenant bağlamını yalnızca aynı Drizzle `tx` üzerinde `set_config(..., true)` ile kuran `withTenant(ctx, fn)` yardımcısını ve ham istemcinin tenant modüllerinden import edilmesini yasaklayan lint kuralını yazmak.
**Okuma listesi (≤5):** `docs/spec/02-tenancy-auth.md §Pooler uyumluluğu`, `docs/INVARIANTS.md I-01…I-03`, `docs/spec/15-engineering.md §DB sözleşmesi`, `docs/STACK.md §ADR-003`, kurulu `drizzle-orm` + seçilen sürücünün transaction ve prepare belgesi (Context7, G-04)
**Dokunulacak dosyalar (≤10):** `packages/db/package.json`, `packages/db/tsconfig.json`, `packages/db/src/client.ts`, `packages/db/src/with-tenant.ts`, `packages/db/src/index.ts`, `packages/db/src/with-tenant.test.ts`, `tests/integration/fixtures/rls-probe.ts`, `tests/integration/with-tenant.int.test.ts`, `eslint.config.mjs`, `pnpm-lock.yaml`
**protected: true** — `eslint.config.mjs` ve sürücü/ORM sürümleri korunan; kullanıcı onaylı PR.

**Yapılacaklar:**
1. Sürücü seçimi (**Q-03** — aday postgres.js / node-postgres / Neon serverless): ölçütler — Drizzle'ın resmî desteği, TCP üzerinden etkileşimli transaction, protokol düzeyi prepared statement'ı kapatıp açabilme, havuz boyutu ayarı. Her aday için belge bağlantısıyla kısa tablo rapora; seçim **"T-005d Neon koşusuna kadar aday"** olarak işaretlenir. `drizzle-orm` + sürücü tam sürüm (`-E`).
2. `client.ts`: `createDbClient({ url, poolMax, prepare })`; üç değer zorunlu, varsayılan **kodda gizli değil**. Üretim/test değeri tek yerde (`DB_CLIENT_SETTINGS` sabiti) — başlangıç `prepare: false` = **A-öneri** (pooler'dan bağımsız güvenli seçenek; doğrulanmadı, T-005d ölçer, T-005e kesinleştirir).
3. `with-tenant.ts`: `withTenant(ctx, fn)` → `db.transaction(tx => …)`; ilk ifade `SELECT set_config('app.current_tenant_id', $1, true)` (parametreli; `SET`/`SET LOCAL`/string birleştirme yasak — 02 §Pooler); `fn` yalnızca `tx` alır. `ctx.tenantId` UUID değilse sorgu atılmadan ret. Hata yutulmaz, transaction geri alınır (G-07).
4. `TenantContext` markalı tip; oluşturucu ve ham istemci yalnızca `@wms/db/internal` alt yolundan (I-01: bağlam doğrulanmış üyelikten gelir — Faz 1 kimlik modülü izin listesine o kartta eklenir). `index.ts` yalnızca `withTenant`, `TenantContext` tipi, `createDbClient`'ı dışa verir.
5. `eslint.config.mjs`: `apps/**` ve `packages/**` (yalnızca `packages/db/**` hariç) içinde `@wms/db/internal`, `drizzle-orm/<sürücü>` ve sürücü paketinin import'u **error** (AC-28 lint kısmı). `tests/integration/**` izinli. Mevcut kurallar gevşetilmez.
6. `rls-probe.ts`: test fikstürü (üretim migration'ı **değil**): `tenant_probe(tenant_id uuid NOT NULL, id uuid, payload text, PRIMARY KEY (tenant_id, id))`, sahibi migration rolü; ENABLE + FORCE RLS; `USING` + `WITH CHECK` politikası 15 §DB sözleşmesi örneğiyle; `wms_app`'e yalnızca SELECT/INSERT/UPDATE/DELETE. `applyProbe(directUrl)` / `dropProbe(directUrl)` doğrudan bağlantıyla; tohum veri sentetik (G-09).
7. `with-tenant.int.test.ts` (uygulayıcı duman testi): `withTenant` içinde yalnız kendi satırları; set_config değeri transaction sonunda bağlantıda kalmıyor. AC testleri **yazılmaz** (T-005c bağımsız yazar).
