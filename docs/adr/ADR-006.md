# ADR-006: Dosya deposu — S3 uyumlu özel bucket, `ObjectStorage` arayüzü arkasında

**Tarih / Durum:** 2026-10-05 · **önerildi**
> I-17: Bu ADR'yi yalnızca kullanıcının GitHub hesabından, PR'ın son commit'ine verdiği inceleme "kabul" durumuna geçirir. Ajanın bu dosyayı düzenlemesi veya Supervisor'ın sohbet beyanı onay sayılmaz.

**Bağlam:**
- v1.3 Azure Blob öneriyordu; ADR-001 dosya deposunu bu ADR'ye bıraktı.
- Azure Blob gerekçesi Azure üzerinde barındırılan veritabanıydı; ADR-004 ile DB Neon oldu, bu gerekçe kalmadı.
- Dosyalar (import/export, belge ekleri, etiket çıktıları) tenant verisidir; herkese açık erişim olmamalı.
- Varsayılan kullanıcıya 2026-10-05'te sunuldu, itiraz gelmedi (`docs/tasks/T-001b.md`); bu onay sayılmaz.

**Seçenekler:**
| Seçenek | Artı | Eksi |
|---|---|---|
| **A. S3 uyumlu özel bucket** (seçilen) | Çok sağlayıcıda aynı API; yerelde MinIO ile aynı protokol; sağlayıcı değişimi adaptör düzeyinde | Sağlayıcı ve bölge ayrıca seçilmeli (ADR-007) |
| B. Azure Blob (v1.3) | Azure ekosistemiyle bütünleşik | DB Azure'da değil; ayrı API, yerel emülasyon farklı |

**Karar:** Seçenek A.
- Erişim yalnızca `ObjectStorage` arayüzü üzerinden; sağlayıcı SDK'sı yalnızca depolama adaptöründe import edilir.
- Bucket özeldir; istemci erişimi kısa ömürlü imzalı URL ile. Nesne anahtarı tenant kimliğiyle öneklenir; yetki kontrolü uygulama katmanında yapılır (anahtar öneki yetki yerine geçmez).
- Yerel geliştirme ve CI: MinIO (`docker compose`).
- Prod sağlayıcısı bu ADR'de seçilmez; bölgesi ADR-007'ye bağlıdır.
- Azure Blob reddedildi (v1.3'ten sapma): tek gerekçesi ADR-004 ile ortadan kalktı.

**Sonuçlar ve riskler:**
- Risk: S3 uyumlu sağlayıcılar arasında davranış farkı (ör. imzalı URL, çok parçalı yükleme ayrıntıları) — adaptör sözleşme testi MinIO'da koşar, prod sağlayıcısında doğrulanmadan "uyumlu" denmez.
- Silme/saklama süreleri KVKK saklama politikasına bağlıdır (`03 §KVKK`); bu ADR süre belirlemez.

**Doğrulama:** `ObjectStorage` adaptör sözleşme testi (yükle/oku/sil/imzalı URL) MinIO'ya karşı; başka tenant önekli anahtara erişimin reddedildiğini gösteren entegrasyon testi.
