# ADR-012: Ajan GitHub kimliği ve onay kaynağı

**Tarih / Durum:** 2026-10-05 · **önerildi** (uygulanmadı; geçici durum aşağıda)
> I-17: Bu ADR'yi yalnızca kullanıcının GitHub hesabından, PR'ın son commit'ine verdiği inceleme "kabul" durumuna geçirir. Ajanın bu dosyayı düzenlemesi veya Supervisor'ın sohbet beyanı onay sayılmaz.

**Bağlam:**
- `docs/agents/PROTOCOL.md §Onay kaynağı (I-17)`: onay, ajanın yazamayacağı bağımsız bir kaynaktan gelmeli; ajanlar ayrı kimlikle push eder; ayrı kimlik kurulamıyorsa ajanın kullanıcı kimlik bilgileriyle çalışıp çalışmadığı bu ADR'de açıkça kaydedilir.
- Kurulum kullanıcının GitHub ayarını gerektirir; ajan bunu yapamaz.
- Varsayılan kullanıcıya 2026-10-05'te sunuldu, itiraz gelmedi (`docs/tasks/T-001b.md`); bu onay sayılmaz.

**Seçenekler:**
| Seçenek | Artı | Eksi |
|---|---|---|
| **A. GitHub App** (önerilen) | Kısa ömürlü token, depo bazlı ince izin, kullanıcıdan ayrık kimlik | Kurulum ve anahtar yönetimi kullanıcıda |
| B. Makine kullanıcısı | Kurulumu basit | Uzun ömürlü kimlik bilgisi; ayrı hesap yönetimi |
| C. Kullanıcının kendi kimliği (mevcut durum) | Ek kurulum yok | Ajan ile insan onayı ayrışmaz; koruma tam değil |

**Karar:** Hedef: Seçenek A (B kabul edilebilir yedek). Ajan kimliğinin yönetici, bypass ve korunan yol inceleme yetkisi yoktur. `main` branch protection: zorunlu `check:all` ve `test:ac`, korunan yollar için CODEOWNERS = kullanıcı, yeni commit'te eski onaylar düşer, yöneticiler dahil bypass kapalı.

**Mevcut durum (2026-10-05, açık kayıt):**
- Ayrı ajan kimliği **henüz yok**. Push'lar bu oturumun GitHub yetkisiyle gidiyor → Seçenek C fiilen geçerli; **koruma tam değil**.
- T-009 tamamlanana kadar `main`'e yalnızca kullanıcı birleştirir.
- Bu durum **bilinen risk** olarak her faz kapısı raporunda tekrarlanır; T-009 kapanınca bu bölüm yerine geçen kayıtla güncellenir.

**Sonuçlar ve riskler:**
- Risk: geçici dönemde ajan, kullanıcıyla aynı kimlikle onay/birleştirme yapabilir; `check:protected` bu dönemde insan onayını kimlikten ayırt edemez.
- Anahtar/token repoya, loga, rapora girmez (G-09).

**Doğrulama:** T-009 sonrası: ajan kimliğiyle korunan yol PR'ının birleştirilemediği ve ajan incelemesinin `check:protected`'ı geçmediği deneme PR'ı; branch protection ayarlarının GitHub API çıktısıyla kaydı.
