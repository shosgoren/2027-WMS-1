# ADR-022: Etiket ve yazdırma yolu — sunucuda ZPL (203 dpi) + tarayıcıdan yazdırılabilir SVG/HTML etiket; yerel köprü kapalı bayrakla

**Tarih / Durum:** 2026-10-06 · **kabul** (Supervisor, ADR-012 rev., 2026-10-06; architect önerisi)

**Bağlam:**
- `07 §Test ve ölçüm`: etiket formatı, DPI ve yazdırma yolu (tarayıcı, yerel köprü, ağ yazıcısı) ADR ile seçilir. ADR-010 bu konuyu kapsam dışı bırakır.
- Pilot profili (A-30, doğrulanmamış): ZPL, 203 dpi, ağ yazıcısı. Uygulama bulutta (Fly.io `fra`, ADR-013) çalışır; müşteri yerel ağındaki yazıcının 9100 portuna sunucudan erişim yoktur. Tarayıcı ham TCP açamaz; `https` sayfasından yazıcının `http` web arayüzüne istek karma içerik olarak engellenir.
- `13 §Yazdırma`: ürün, lokasyon, koli etiketleri (ZPL/PDF); şablon sürümü belgeye kaydedilir.

**Seçenekler:**
| Seçenek | Artı | Eksi |
|---|---|---|
| A. Sunucudan yazıcıya doğrudan (9100/IPP) | Sürücü gerekmez | Müşteri ağına giriş (VPN/port yönlendirme) gerekir; çok kiracılı SaaS'ta güvenlik riski; pilot için kurulum yükü |
| B. Yerel köprü (Zebra Browser Print veya kendi ajanımız) ile ham ZPL | Yazıcının yerel çözünürlüğünde net barkod | Ek kurulum; Zebra yazılımının lisans/sürüm koşulları bu ADR'de doğrulanmadı (G-04); kendi ajanımız ayrı dağıtım hattı |
| C. Tarayıcıdan yazdırma: etiket boyutunda SVG/HTML (CSS `@page`), işletim sistemine sürücüyle eklenmiş ağ yazıcısına | Ek yazılım yok, her cihazda çalışır; bağımlılıksız | Barkod rasterleştirmesi sürücüye bağlı; 203 dpi'de modül genişliği nokta katına oturmazsa okunabilirlik düşer |

**Karar:** C birincil yol; B kapalı bayrakla hazırlanır; A reddedildi.
1. Etiket içeriği tek şablon tanımından (sürümlü, `label_template_version` metni) iki çıktıya üretilir: (i) **ZPL II** (203 dpi, nokta cinsinden sabit koordinatlar, Code 128 `^BC`), (ii) **SVG** (Code 128, modül genişliği 203 dpi nokta katlarına yuvarlanmış mm cinsinden; CSS `@page` ile etiket boyutu).
2. Code 128 kodlayıcı kendi kodumuzdadır (saf işlev, altın vektör testleri); yeni bağımlılık eklenmez.
3. Kullanıcı yolu: "Etiket yazdır" → önizleme → tarayıcı yazdırma (C). "ZPL indir" düğmesi aynı içeriği `.zpl` dosyası olarak verir (yazıcıya elle gönderim/teşhis). B yolu (`LABEL_LOCAL_BRIDGE_ENABLED`, varsayılan kapalı) yalnızca arayüz noktası olarak bırakılır; açılması pilot cihaz doğrulaması + yeni ADR eki ister.
4. Etiket boyutu ve içerik alanları iş kuralıdır; doğrulanana kadar varsayım (`A-` etiketli, T-312) ve tenant ayarına taşınmaz.

**Sonuçlar ve riskler:**
- Risk: sürücü ölçeklemesi barkodu bozabilir → pilot yazıcısında basılan etiketin pilot okuyucusuyla okunması AC-35 cihaz matrisinin parçası olur; başarısızsa B yolu öne alınır (ADR eki).
- ZPL çıktısı yazıcıda doğrulanmadan "ZPL desteklenir" denmez; birim testleri yalnızca metin düzeyinde kanıttır.
- Koli/palet etiketi (SSCC) pilot `UNIT_ONLY` (A-20) olduğundan 3A'da yoktur.

**Doğrulama:** Code 128 altın vektörleri (kontrol karakteri dahil); ZPL çıktısının sabit şablonla birebir metin testi; SVG modül genişliği 203 dpi nokta katı testi; pilot yazıcısında basılan ürün ve lokasyon etiketinin AC-35 matrisindeki okuyucuyla okunması (T-320, cihaz yoksa "çalıştırılmadı").
