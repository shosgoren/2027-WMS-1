# ADR-013: Barındırma platformu ve dağıtım yolu — Fly.io (Frankfurt) + GitHub Actions

**Tarih / Durum:** 2026-10-05 · **kabul** (ADR-012 rev.: Supervisor kabul eder)

**Bağlam:**
- ADR-001 uzun ömürlü worker süreci ister; platform seçilmemişti. ADR-007: DB, dosya deposu ve worker aynı AB bölgesinde. ADR-004: Neon (AB bölgesi — `aws-eu-central-1`, Frankfurt; Q-01 kapanışı T-005'te doğrulanır).
- Ajan ortamının ağ politikası sağlayıcı API'lerine (neon.tech, fly.io vb.) çıkışa izin vermiyor (`host_not_allowed`, 2026-10-05); GitHub erişimi var.
- Kullanıcı yalnızca hesap gerektiren işlere dahil olmak istiyor (ADR-012 rev.).

**Seçenekler:**
| Seçenek | Artı | Eksi |
|---|---|---|
| **A. Fly.io `fra` + Tigris (S3 uyumlu, Fly üzerinden)** (seçilen) | Web + worker aynı uygulamada ayrı süreç grupları; Docker imajı; Frankfurt; dosya deposu ek hesap istemez | Kredi kartı gerekir; Tigris davranışı MinIO ile sözleşme testiyle doğrulanmalı (ADR-006) |
| B. Vercel (web) + ayrı worker barındırma | Next.js için en kolay | İki platform, iki hesap; worker için yine ikinci sağlayıcı |
| C. Render/Railway | Basit arayüz | Worker ücretli/ayrı; bölge seçenekleri dar |

**Karar:** A.
- Tek Docker imajı (`apps/web` standalone + `apps/worker`), Fly `processes`: `web`, `worker`; bölge `fra`. Ortamlar: `staging` (her `main` birleşmesinde otomatik) ve `prod` (faz kapısında Supervisor etiketle tetikler).
- **Dağıtım yalnızca GitHub Actions'tan** yapılır; sırlar GitHub repo sırlarında: `FLY_API_TOKEN`, `NEON_API_KEY` (+ değişken `NEON_PROJECT_ID`), isteğe bağlı `RESEND_API_KEY`. Ajan oturumu sırları görmez (G-09).
- Migration'lar dağıtım işinde doğrudan (pooler'sız) Neon bağlantısıyla, uygulama başlamadan önce koşar (genişlet–taşı–daralt, G-08). CI entegrasyon testleri her koşuda geçici Neon dalı (branch) açar ve kapatır (T-005d/e).
- İşlemsel e-posta: Resend (AB bölgesi) `Mailer` arayüzü arkasında; anahtar yoksa canlı ortam e-posta göndermez, davet/şifre bağlantısını yöneticiye ekranda gösterir (kapalı bayrak, G-07).

**Sonuçlar ve riskler:**
- Hukukçu onayı (Q-07) gelmeden canlı ortam yalnızca demo/sentetik veri taşır; giriş sayfasında "demo ortamı" uyarısı.
- Tigris'in S3 uyumluluğu ADR-006 sözleşme testiyle staging'de doğrulanmadan dosya özellikleri açılmaz.
- Maliyet: kullanıcının Fly ve Neon planına bağlı; Supervisor makine boyutunu en küçük tutar (web 1×shared-cpu-1x 512MB, worker 1×shared-cpu-1x 256MB) ve ölçekleme yapmaz.

**Doğrulama:** staging dağıtım işinin yeşil koşusu; `/api/health` (DB + kuyruk) 200; worker'ın test işini işlediği smoke testi; Tigris'e karşı `ObjectStorage` sözleşme testi.
